## Exact scientific scope

The machine profile represents 32 virtual stabilizer qubits with exact Pauli algebra. Entropy controls a phase operation through actual CPUID/RDSEED execution. The legacy dense profile supports non-Clifford operations on up to 20 virtual qubits using Q30 arithmetic, and remains a separate execution profile. Neither is evidence of physically coherent qubits, quantum advantage or a new physical quantum device.

Complete reversal means reversal of the complete recorded canonical machine/seed history. The journal explicitly retains information overwritten by entropy and control transitions. It does not claim unrecorded entropy can be recovered from a final state alone, or that the physical host is run backward. Journaling digital quantum-state representations is not physical quantum-state cloning.

The supplied closed-routine state is a controlled execution of preserved source, not a recovered exact latest trained/live neural checkpoint. Full trained-state recovery, Windows/ARM64 execution and physical quantum coherence remain research boundaries. The reference sanitizer build retains its LeakSanitizer/host-tracing failure; it is not promoted to a complete sanitizer pass.

## Source and size decision

G9 contained 229 files / 923,590 uncompressed bytes in a 279,329-byte ZIP. Its compactness was real, but self-contained building did not prove the original compiler/history/nesting scope. G11 adds working implementations and raw execution histories, rather than padding the archive with inactive project trees.

The recovered BF13 volume's CRC and all 193 checkpoint-manifest entries were checked. Only the six source/header files actually used by compatibility tests, plus their existing license and notice, are included. No HX89 source is copied. Indexed earlier conversation requirements were recovered; a full raw transcript was not available, so no verbatim whole-chat review is claimed.
